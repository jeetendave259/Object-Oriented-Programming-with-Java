Topic 1

Object-Oriented Programming

Object-oriented programming is a programming style where the real world is modelled as objects that hold data and behaviour. Java is built around this model, which helps produce cleaner, reusable, and better-organized software.

Instead of writing one long list of instructions, programmers define classes that describe a concept, then create objects from those classes. This makes it easy to reuse code and manage complexity in larger programs.

Topic 3

Encapsulation

Encapsulation keeps the internal data of an object protected and controlled. It allows other parts of the program to interact with the object through a defined interface instead of directly changing its internal state.

In Java, private fields are commonly used inside a class so that data cannot be modified accidentally from outside. Methods are then used to read or update that data safely.

Protected data inside a class boundary
public setAge()
public getAge()
private int age;
→
Safe control
Hidden data
Example
class Person {
    private int age;

    public void setAge(int age) {
        this.age = age;
    }

    public int getAge() {
        return age;
    }
}

Inheritance

Inheritance lets one class inherit properties and methods from another class. This helps reuse common logic and create a hierarchy where specialized classes extend general ones.

When a child class extends a parent class, it automatically gains the parent’s fields and methods, while also adding its own unique behaviour.

Class hierarchy

Dog
Cat
Bird
Example
class Animal {
    void eat() {
        System.out.println("Animal is eating");
    }
}

class Dog extends Animal {
    void bark() {
        System.out.println("Dog is barking");
    }
}

Abstraction

Abstraction focuses on what an object does instead of how it does it. It hides implementation details and exposes only the essential features that users need.

This keeps code simpler and safer because callers do not need to know internal logic. Abstract classes and interfaces are common ways to apply abstraction in Java.

Abstract concept
abstract class Shape {
    abstract void draw();

Topic 6

Polymorphism

Polymorphism means one object can take many forms. In Java, the same method or reference may behave differently depending on the actual object instance being used.

A parent type reference can point to a child object, and the method call resolves according to the actual object at runtime. This allows flexibility and extensibility in programs.

Reference and object relationship
Shape reference
→
Circle object
Example
class Shape { void draw() { System.out.println("Drawing shape"); } }
class Circle extends Shape { void draw() { System.out.println("Drawing circle"); } }

Shape s = new Circle();
s.draw();

Classes

A class is a blueprint or template that defines the fields and methods of a type. It describes what an object knows and what it can do.

A class usually represents a real-world entity such as a person, a vehicle, a bank account, or a product. It defines the structure and the behaviour shared by all objects of that class.

    String breed;
    int age;

new Operator

The new operator creates an object in memory and returns a reference to it. Without new, the class exists only as a template, not as a usable runtime object.

When you write new Box(), Java allocates the required memory and calls the constructor as part of object initialization.

Topic 12

Method Overloading

Method overloading allows multiple methods in the same class to share the same name but use different parameter lists. Java chooses the correct version based on the arguments passed.

This is useful when related operations need the same conceptual name but different inputs. For example, an add method might accept two integers, two doubles, or one integer and one float.

Different method signatures

float add(int a, float b)

Topic 13

Recursion

Recursion is a technique where a method calls itself until it reaches a stopping condition. The method solves a smaller version of the same problem each time.

Recursion is helpful for tasks such as factorial, Fibonacci, tree traversal, and divide-and-conquer algorithms. The base case is essential to prevent infinite recursion.

Recursive call stack
Example
class Factorial {
    static int factorial(int n) {
        if (n == 1) return 1;
        return n * factorial(n - 1);
    }
}

Topic 14

Constructors

A constructor is a special method used to initialize an object when it is created. It has the same name as the class and is called automatically when new is used.

If no constructor is written, Java provides a default constructor. A class can also define multiple constructors with different parameter lists, which is called constructor overloading.

Constructor flow
1. Memory allocated
2. Constructor called
3. Object ready
Constructor overloading
Box()
Box(double w, double h, double d)
Example
class Box {
    double width, height, depth;

    Box() {
        width = 10; height = 10; depth = 10;
    }

    Box(double w, double h, double d) {
        width = w; height = h; depth = d;
    }
}
